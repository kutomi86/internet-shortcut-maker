# Save Page as Internet Shortcut

A Chrome extension that saves the active tab as a `.url` file via hotkey, context menu, or toolbar popup.

## Features
- Save active tab as an Internet Shortcut (.url) file.
- Support for hotkey triggers.
- Support for Context Menu saving.
- Simple popup interface.

## Installation
1. Download or clone this repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the extension directory.
